# Aset website

Disematkan ke `index.html` saat `toefl_gen site` membangun website, jadi website tidak memuat apa pun dari luar.

- `logo.png`: logo TOEFL Academy lengkap, untuk layar kata sandi.
- `logo-mark.png`: ikon logo tanpa tulisan (dipotong dari `logo.png`, 103 px), untuk sidebar dan ikon tab.
- `fonts/manrope-latin.woff2` dan `fonts/dm-sans-latin.woff2`: subset Latin dari font yang sama dengan SKD Generator.
  Keduanya berlisensi SIL Open Font License 1.1 (Manrope oleh Mikhail Sharanda, DM Sans oleh Colophon Foundry dan
  Google), jadi boleh disematkan dan dibagikan bersama website.
